About this experiment
Every game here is built from the same tower-defense prompt, handed to a range of frontier models as a way to compare them head-to-head. Each is typically a single one-shot generation — occasionally with one or two follow-up prompts, only to nudge the theme somewhere more distinctive or to fix a bug that stopped it from running at all. Afterward each entry gets a light post-processing pass from me for responsive / mobile layout and to fit the site shell (the back button, framing, and so on). The badge in the corner of each card shows which model and effort level produced it.
