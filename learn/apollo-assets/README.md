# Apollo web assets

The film, poster, and captions are produced by the [ManimGX source and render script](../../scripts/apollo/README.md).

`Anton-Regular.ttf` is the Anton display typeface from the [Google Fonts source repository](https://github.com/google/fonts/tree/main/ofl/anton). It is bundled locally so the page retains its condensed typography without a third-party font request or depending on an installed desktop font. Its original SIL Open Font License is included as `Anton-OFL.txt`.
