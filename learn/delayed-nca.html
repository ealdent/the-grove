Signals
take time.

One tiny rule, shared by every cell. What changes when a neighbor’s signal arrives late? Compare the same starting field with instant communication and distance-dependent memory. Then teach a small neural network the rule yourself.

What should I see?

The rule mixes neighbors, then amplifies what remains. Each cell has a value from −1 to +1. It moves 22% toward its neighbors’ average, then adds 0.12 × self × (1 − self²), pushing positive values toward +1 and negative values toward −1. The result is clamped to [−1, 1].

Try Positive pulse, seed radius 5, neighborhood radius 3, delay 1. You should see a bright patch spread outward over ticks 10–40, with the delayed panel trailing. This is growth and smoothing, not an oscillating wave. Eventually the patch can fill the grid. The student learns to imitate this one-step rule; it is not trained to make a particular picture or long-term animation. This demonstrates delay and one-step imitation; it does not establish that delays solve a useful task.

The exact experiment

Space, time, and a shared rule

mᵢ(t) = mean of Sⱼ(t − dᵢⱼ × delay)
Sᵢ(t+1) = clamp(Sᵢ(t) + f(Sᵢ(t), mᵢ(t)), −1, 1)

One clock, no turn-taking

The displayed field is S(t), starting at S(0). Each tick reads only complete saved fields and writes a separate next field. A nearby cell updated earlier in the loop cannot affect another cell in that same tick. The cell’s own state always comes from S(t).

Before the seed, silence

For every negative time, S(t) = 0. With delay 1, ring d reads S(t−d). A signal placed in S(0) first enters a distance-d update when t=d; its effect appears in S(d+1). The extra tick is the update itself. Delay 0 reads S(t), including at the first update.

The edges join up

The 48 × 48 grid wraps horizontally and vertically (a torus). Neighborhoods use wrapped offsets. Fixed mode uses radius R immediately. Expansion uses r(t) = min(R, t+1), starting at radius 1. Expansion is an independent neighborhood schedule, not a different definition of travel time.

What is learned?

A neural rule, a modest task

The reference rule supplies the training targets

Its residual update is 0.22(m−s) + 0.12s(1−s²): neighbors encourage mixing, while local growth pushes values toward positive or negative saturation. Initial fields and colors are also designed, not learned.

The student really adjusts its weights

The student uses eight tanh hidden units, a linear output, and no biases: 24 weights in total. Gradient descent with Adam minimizes mean squared error against the reference rule’s residual on random (self, neighbor-mean) pairs in [−1,1]². A separate seeded sample reports held-out error. No biases means an all-zero input stays exactly zero.

Learning the rule is not learning the whole future

The network does not train through multiple simulation ticks or learn how to compensate for delay. Small one-step errors can accumulate. Changing the signal history changes the dynamics, so the delayed system is not mathematically equivalent to an ordinary current-neighbor cellular automaton. Clamping guarantees bounded states, not correct long-term behavior.

Try a controlled comparison

Choose Positive pulse with seed radius 5 and neighborhood radius 3. Step once: at delay 1 the delayed panel has no received seed signal yet. Then run to ticks 10–40: the activated patch spreads, with the delayed front trailing the baseline. The panel counts cells at state ≥ 0.1 using the same fixed threshold in both fields. Train the student and repeat; its front differs because training fits only one-step updates. Set delay to 0 to check exact agreement. A radius-0 seed is a one-cell diagnostic that fades almost to zero; it is not the recommended propagation example. This is a growing patch, not a sustained oscillating wave: eventually a positive seed can fill the periodic grid with near-uniform activation.

Context & sources

Growing Neural Cellular Automata (Distill, 2020) is background for learned shared local updates. This small supervised scalar example is not its image-growing architecture or training recipe. Distance-dependent delays in spiking networks are adjacent context, not evidence of a matching cellular automaton. An exact published match for this delayed, expanding-ring mechanism has not been established here.

TextNCA (2026) explores language modeling with a 30.8M-parameter model and staged attention windows of 8, 32, and 128 tokens. Widening those windows is different from reading distance-indexed past states. This prototype does not reproduce TextNCA or train a language model.
