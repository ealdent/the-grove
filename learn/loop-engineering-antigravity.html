02 The Spectrum of Loops in Antigravity

Antigravity orchestrates multiple nested loops running across different time scales and execution scopes to maintain maximum context cleanliness and code quality.

Inner Loop < 1s Latency

Tool Execution Loop

Local synchronous edit-test cycles (`replace_file_content` $\rightarrow$ `run_command` lint/build $\rightarrow$ parse compiler output). Resolves syntax errors instantly before escalating.

Scope: Single File / Function
Context Cost: Low (Local Diffs)
Primary Tool: replace_file_content
Swarm Loop Concurrent

Subagent Parallel Swarm

Delegates exploratory research, refactoring, or multi-step analysis to isolated background subagents (`invoke_subagent`). Keeps the parent context clean.

Scope: Isolated Worktree / Branch
Context Cost: Zero Parent Context Bloat
Communication: send_message / Reactive Wakeup
Memory Loop Persistent

Self-Improvement Loop

After any correction or runtime failure, the agent logs lessons to tasks/lessons.md. These anti-patterns automatically constrain all future loops.

Scope: Cross-Session / Project-wide
Feedback Signal: User Corrections & Failures
Target Artifact: tasks/lessons.md
Scheduled Loop Background

Cron & Monitoring Loops

Background timer loops (`schedule`) that monitor long-running builds, test suites, or remote deployments, waking the agent reactively upon completion.

Scope: Long-running Processes
Mechanism: schedule (One-shot / Cron)
Control Tool: manage_task
03 Antigravity Loop Engineering Principles

Four fundamental laws for engineering bulletproof agentic loops in production software environments.

01

Empirical Evidence Dominance

Never hypothesize a fix based on assumptions. Always read un-truncated compiler logs, stack traces, and runtime outputs before mutating source code.

02

Strict Termination Guardrails

Every loop must have a deterministic stop condition (unit test passing, exit code 0, explicit task checklist item checked in tasks/todo.md) to prevent infinite tool thrashing.

03

Context Offloading via Subagents

Researching wide codebases or parsing 10,000-line logs degrades context quality. Offload research to background subagents so the primary agent stays sharp.

04

Staff-Engineer Verification Bar

Editing a file is never the end of a task. The loop is only closed when clean build output, automated tests, and live runtime behavior prove correctness.
