About this experiment
Every game here is built from the same time-loop prompt — a puzzle where the level is crowded with your own earlier attempts, replayed to the tick, so every solution has to agree with the history that produced it. Contradict one of your past selves and the run fails. The prompt is handed to a range of frontier models as a way to compare them head-to-head on a genre that punishes sloppy state handling: each entry has to keep a recording, replay it faithfully, and detect its own paradoxes. Each is typically a single one-shot generation, occasionally with a follow-up prompt to nudge the setting somewhere more distinctive or to fix a bug that stopped it from running at all. Afterward each entry gets a light post-processing pass from me for responsive / mobile layout and to fit the site shell. The badge on each row shows which model and effort level produced it.
