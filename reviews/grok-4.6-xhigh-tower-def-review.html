Thirty-eight tower defenses, one scale

A code-first grading of every game in tower-def/. Written by Grok 4.6 xHigh. The file is public if you have the URL. It is not in any index.

2026-08-30 · addendum 2026-09-01 · 38 HTML games · scores 11–89 · none at 90+

How the scale works

Zero is a page that does not load. One hundred is a unique, flawless game that would stand as a paragon of single-file tower defense at this scale. This batch does not have a 90. Two or three get close. A useful scale has to use the rest of the ruler. A pile of 70s would be a shrug.

Originality is not a tax on the early games. Through about May 2026 the prompt was “make a tower defense,” not “make a distinctive one.” Generic fantasy, candy, and emoji are not deducted. If an older file still invented a metaphor that changed play — 3 AM, Spin Cycle, Excel’s spreadsheet skin, Candy Circuit’s upgrade callbacks — that is called out as a bonus. From June onward the prompts were asking for identity, so a late file that ships a template kit is graded as a missed brief.

The score is not a vibe. It is four things, in order:

  1. Does it function as a tower defense? Load, place, path, fire, economy, wave lifecycle, win/lose. A missing combat loop is fatal. A missing sell button is not.
  2. Do the advertised systems exist in the source? Splash that never splashes, slow upgrades that never enter the movement formula, “chrono” with no time mechanic, “the world obeys the map” with no map authorship — those are scored as lies, not flavor.
  3. Is it a complete campaign at this scale? Authored or budgeted waves, distinct tower roles, a win state, upgrades that change behavior, some juice. Audio is expected in the late era and treated as a hole when absent.
  4. Is the code something you could maintain? dt vs frames, spawn-queue mutations, phase gates that match the UI copy, a single damage pipeline, no dead data.

Every file was read in full. Inline JavaScript in all 38 parses. Headless Chrome in this environment fought a profile lock and a virtual-time hang, so runtime claims below are proven from the shipped logic, not from a play session. Where a bug is named, the branch is in the file.

What the ranking is actually saying

The top three are all Anthropic Opus files, and they are not interchangeable. Lampblack invents a visibility economy. Tidepool invents a clock that the rest of the sim obeys. 3 AM invents a metaphor in April, before that was the assignment, and still finishes the campaign. Those are the only scores I would defend as “approaching 90.”

A September addendum: Fable 5.1 Max shipped Marginalia after this page was first written. It is #4. The chart is generated, the blight traits have counters, and the cartouche’s “after each blight” patronage pays once per wave. That is why it sits under 3 AM and over Mourningbloom.

The 70s are finished games. You can sit down and play them. They are not paragons. A lot of late files live here because they did the assignment — five towers, four upgrades, twenty-four waves, a vibe — without a mechanic that would survive a reskin.

Below 50 the files start failing the job. Frame-locked sims. Dead upgrade stats. A 3D “FPS” with no gun. A July DeepSeek that still cannot splash. One Grok Heavy that never wrote the attack loop.

Lampblack

Opus 5 Ultra · 2026-07-24 · late era · 162 KB · opus5-ultra-tower-def.html

Coal-pit horror where light is the weapon

originality expectedApproaches 90

The closest thing in this batch to a real designed game. Shroud is not flavor.

What’s in the file

5 machines × 5 named tiers; 17 enemies; 25 named shifts with modifiers; lumen reveal, nightcap smother, sonar ignore-shroud, lightleech, burrow, healers; prep-only build; Web Audio.

Code

Professional monolith. Named tiers, dirty-flag UI, a real damage pipeline, art shared between shop and board. Reads like a spec, not a prompt dump.

Proven from the source

  • hurt() multiplies damage by 0.45 when !e.revealed unless ignoreShroud is set.
  • Shrouded enemies move at 1.18× and regenerate 0.9% max HP per second.
  • Reveal pass aggregates core + tower lumen radii, then nightcap and sonar override it.
  • Shift modifiers (blackout, firedamp, veil) actually change those numbers.

Held back by

  • 165 KB of density will bounce casual players.
  • No endless mode; sell refund is a stingy 55%.
  • Not flawless: complexity hides balance questions a playtest pass would catch.
