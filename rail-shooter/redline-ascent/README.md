# Redline Ascent

An endless pseudo-3D arcade shooter built with React, TypeScript, Canvas 2D, and procedural Web Audio.

## Development

```sh
npm install
npm run dev
```

Vite serves `index.source.html` for development.

## Standalone build

```sh
npm run build
```

The build compiles the app, embeds its JavaScript, CSS, and sprite images, then writes `index.html`. Open that generated file directly in a browser; no local server is required.
