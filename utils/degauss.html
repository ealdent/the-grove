Four tape lengths.

Not monospaced, not proportional. Every character takes one of four fixed widths, named like cassettes: 30, 45, 60 and 90 are the 2 : 3 : 4 : 6 of an octave, a fifth and a fourth.

Two C30s make a C60. Three make a C90. Two C45s make a C90.Every width is a multiple of 150 units.

Space, figures and box drawing are all C60, so indentation, trees and tables of figures still line up on the C60 cell. The four space characters (C30, C45, C60, C90) can close any gap of two steps or more, so even mixed lines can be aligned exactly.

EDIT MEDEGAUSS / REGULAR

Built like equipment.

A small set of rules, applied everywhere: square where a stem runs on, round where the tube curves, and a notch at every joint.

o

Picture-tube bowls

Every bowl is a squircle, the shape of a 1970s screen. Where a stem runs straight on, the corner stays square.

n

Bloom traps

The notch at each joint is drawn in on purpose. A lit tube blooms where strokes meet; the traps fill with that glow, so a glowing n stays as even as a printed one.

0O

The power-off zero

Switch off a tube and the picture collapses to one bright point. The zero keeps that point, clear of the walls, so it never reads as O, Ø or θ.

i;

Phosphor dots

Tittles, periods, colons and accents are true circles: the beam spot among the squircles.

2359

Segment figures

2, 3, 5, 6 and 9 come from the seven-segment display, with the corners rounded off. All figures are C60, so columns of numbers line up.

On your computer
Open both .ttf or .otf files. On macOS choose Install in Font Book; on Windows right-click and choose Install; on Linux copy them to ~/.local/share/fonts/ and run fc-cache -f.

          
In your editor
Set the font family to Degauss and turn ligatures on. Regular and Bold are one family, so editors that bold keywords use the real Bold. Read the font notes.

          
On the web
Keep the WOFF2 files beside degauss.css and link the stylesheet. Add degauss-phosphor for the glow, or degauss-prose to tighten word spaces in running text.

        

        

          Self-hosted CSS example
          
Put this beside the downloaded WOFF2 files.


@font-face {
  font-family: "Degauss";
  src: url("Degauss-Regular.woff2") format("woff2");
  font-weight: 400;
  font-display: swap;
}
@font-face {
  font-family: "Degauss";
  src: url("Degauss-Bold.woff2") format("woff2");
  font-weight: 700;
  font-display: swap;
}
pre, code {
  font-family: "Degauss", ui-monospace, monospace;
  font-variant-ligatures: contextual;
}
