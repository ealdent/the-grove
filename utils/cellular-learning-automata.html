How it works

1 · What is a Learning Automaton?

A Learning Automaton (LA) is a simple decision-making entity. It has a set of actions (e.g. choose Blue or Orange) and a probability vector that tracks how likely it is to choose each action. It randomly selects an action based on these probabilities, applies it to an environment, and receives a response (Reward or Penalty). Over time, it updates its probabilities to favor actions that yield rewards.

2 · Adding the "Cellular" aspect

A Cellular Automaton (CA) is a grid of cells that evolve based on local rules (like Conway's Game of Life). In a Cellular Learning Automaton (CLA), we put a Learning Automaton inside every cell. The "environment" for each cell is simply its neighboring cells. The cells learn collectively through local interactions, leading to emergent global behaviors without centralized control.

3 · The Linear Reward-Penalty Algorithm

In this demo, we use the L_{R-P} scheme. If a cell chooses action $i$ and gets a reward, its probability for $i$ increases toward 1: pi ← pi + α(1 - pi) pj ← (1 - α)pj If it gets a penalty, its probability decreases, and alternatives increase: pi ← (1 - β)pi pj ← β/(r-1) + (1 - β)pj

4 · Emergent Consensus

Our environment rule is simple: a cell gets a reward if its action matches the majority of its 8 neighbors (Moore neighborhood). Otherwise, it gets a penalty. Though no cell can see the whole grid, the local desire to agree with neighbors creates a cascading effect. Over time, domains of consensus form, merge, and stabilize, showcasing how distributed RL agents can solve global coordination problems.
