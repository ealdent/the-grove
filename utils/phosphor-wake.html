01 / Install on your computer

Download either TTF. On macOS, open it in Font Book and choose Install. On Windows, right-click and choose Install. On Linux, place it in ~/.local/share/fonts/ and refresh your font cache.

02 / Choose it in your editor

Select Phosphor Wake or Phosphor Wake Burn as your font family. Restart your editor if it doesn’t appear. The font stays monochrome; glow depends on your app’s rendering support.

03 / Put it on the web

Keep the WOFF2 files beside the included CSS and link the stylesheet. Regular suits smaller code; Burn rewards display sizes. Read the complete font notes ↗

View a self-hosted CSS example

Place this CSS beside the downloaded WOFF2 file.

@font-face {
  font-family: "Phosphor Wake Burn";
  src: url("PhosphorWake-Burn.woff2") format("woff2");
  font-weight: 400;
  font-display: swap;
}
.terminal {
  font-family: "Phosphor Wake Burn", monospace;
  font-weight: 400;
  font-synthesis: none;
  background: #08170f;
  color: #b9ff91;
  text-shadow: 0 0 2px #b9ff91, 0 0 10px #b9ff91,
               0 0 28px #b9ff9199;
}
